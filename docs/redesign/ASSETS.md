# Illustration inventory

All visuals are original SVG React components stored with the source. No stock photos, external image links, raster generation or fabricated screenshots are used. SVG scales with its container; no separate image download is required.

- `AdventureVisuals.jsx`: UniverseIllustration (two children, original Questy, floating laboratory/castle/robotics islands, stars and a ringed planet); WorldScene and its shared island foundations; technology, science, art, media, engineering, business, helping, nature and photography environments; GameArtwork; explorer BadgeArtwork; illustrated empty/loading states; saved-game celebration.
- `QuestyMascot.jsx`: preserved existing silhouette and palette with happy, curious, thinking, celebrating and encouraging expressions.
- `ActivityLandmarks.jsx`: fashion/design, music, cooking and interior-design objects in the same visual language.
- Decorative art is hidden from accessibility APIs; informative illustrations carry descriptive labels. No illustration is labelled as an actual game screenshot. Actual before/after screenshots live in `screenshots/`.

Public cards and playable cards share `src/data/catalog.js`. The marketing site describes the real collection, while its preview dialog does not pretend to run a game.
